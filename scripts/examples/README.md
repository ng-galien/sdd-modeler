# Script Examples

This folder contains example SDD model files used by the test scripts.

These are the fixtures that the scripts use by default. They may be copies of the canonical `instructions/examples` files or simplified 'mini' versions used for readability in test reports.

Do not edit these files in place for documentation purposes. Edit `scripts/examples` (or `state-modeler-app/src/test/resources/examples`) and update fixtures if tests must be aligned.
